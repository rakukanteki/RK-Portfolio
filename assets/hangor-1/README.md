# Hangor 1.0 figures

Source: Team BengalSub, *Technical Design Report of Hangor 1.0, An Autonomous Underwater Vehicle*, RoboSub 2025 (user-supplied RoboSub25_TDR-BengalSub.pdf).

- `mechanical-design.png`: Figure 3, page 3. AUV designed in SolidWorks.
- `power-distribution.png`: Figure 9, page 4. High-level power distribution system.
- `gate-detection.png`: Figure 12, page 5. Gate detection using YOLOv8.

Images were extracted directly from the PDF at their original embedded resolution and converted to PNG. No labels or technical content were altered. The source images are small; enlarging them cannot recover additional detail.

Page copy summarizes Sections I–V and Appendices D–E. Competition task descriptions represent the report’s mission design, not a claim that every task was completed in competition. Battery ratings and controller model details vary within the report, so the web description avoids those conflicting specifications.
